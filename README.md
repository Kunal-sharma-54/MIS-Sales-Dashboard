# MIS Sales Dashboard

A simple web-based MIS Sales Dashboard connected to Google Sheets using Google Apps Script.

## Features

- View sales data
- Search and filter data
- Filter by Salesman and Material Centre
- Date-range filtering
- Sort by Date, Quantity and Amount
- Salesman-wise summary
- Sales chart using Chart.js
- Add new sales entries
- Refresh data
- Loading and error handling

## Technologies Used

- HTML
- CSS
- JavaScript
- Google Sheets
- Google Apps Script
- Chart.js

## Project Structure

```text
MIS-Web-App/
├── index.html
├── script.js
├── style.css
└── README.md
```

## How It Works

```text
Google Sheet
     ↓
Google Apps Script
     ↓
JavaScript
     ↓
MIS Dashboard
```

The dashboard fetches sales data from Google Sheets through Google Apps Script and displays it on the web page.

## Run Locally

Open the project in VS Code and run `index.html` using **Live Server**.
